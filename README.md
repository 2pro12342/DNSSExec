# DNSSExec
Domain Name Server Script Execution: An exploit/guide for school chromebooks to execute javascript on pages by setting up MITM Proxy and Dnsmasq, then connecting to a DNS server. Linux Environment and Dev Mode is required. 
  
## Download 
  
Download one of the 2 files or copy the data url link and paste it into a new tab. 
  
**Note**: If the  data url instantly closes, input `data://` instead of `data:`.
